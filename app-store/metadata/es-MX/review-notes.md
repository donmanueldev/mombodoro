# Notas para App Review

Mombodoro no requiere inicio de sesión. Desmarca “Sign-in required”.

La aplicación funciona completamente en el dispositivo y no incluye compras dentro de la app, suscripciones, publicidad ni analítica.

Flujo sugerido para revisión:

1. Abre Mombodoro y selecciona “Pomodoro”.
2. Abre Tareas, añade una tarea y selecciónala.
3. Inicia, pausa y continúa el temporizador.
4. Abre Ajustes para cambiar las duraciones y enviar una notificación de prueba.
5. Usa “Cambiar sesión” para volver al selector inicial.

La aplicación solicita permiso para mostrar notificaciones locales. Ese permiso se utiliza exclusivamente para avisar cuando una sesión está por terminar o ha finalizado.

Contacto de revisión: pendiente de completar directamente en App Store Connect.
