Política de privacidad

Última actualización: 8 de septiembre de 2026

Mombodoro se ha diseñado como una aplicación de escritorio para gestionar ciclos de enfoque, descansos y tareas. Esta política explica el alcance de datos de la versión actual.

Datos que utiliza la aplicación

La aplicación usa la información que introduces para mostrar tus tareas y el estado de las sesiones durante el uso. La versión actual no incluye cuentas, sincronización en servidores, analítica ni publicidad.

Notificaciones

Si activas los avisos, Mombodoro puede utilizar las notificaciones de macOS para informarte al completar una fase. Puedes gestionar ese permiso desde los ajustes del sistema operativo.

Datos en el sitio web

Esta web estática no tiene formularios de registro, cookies propias ni herramientas de analítica integradas. Al seguir un enlace externo, se aplicará la política de privacidad de ese sitio.

Cambios a esta política

Si cambian las funciones relacionadas con datos, esta página se actualizará antes de que el cambio entre en vigor.

Contacto

Para cuestiones sobre privacidad, puedes abrir una consulta en el repositorio del proyecto.
